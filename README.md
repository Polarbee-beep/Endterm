# BlockCrafters - Endterm Project

## Project Description

BlockCrafters is a Minecraft building commission website.
It provides information about building services, pricing,
portfolio projects and contact information.

## Pages

1. Home
2. About
3. Services
4. Gallery
5. Contact

## JavaScript Features

- Two arrays storing projects and services.
- Loops: for, for...of and forEach.
- Six reusable functions.
- Dynamic DOM manipulation.
- Project search.
- Category filtering.
- Favorites system.
- Dark and light theme switcher.
- Price estimator.
- Form validation.

## jQuery Features

- ID and class selectors.
- closest() and children() traversal.
- Click events.
- Keyboard events.
- Mouseenter events.
- slideToggle() animation.
- fadeTo() effect.

## Form Validation

The contact form checks:
- Name length.
- Email format.
- Discord username.
- Selected package.
- Project description length.

## How to Run

1. Download or clone the repository.
2. Open index.html using Live Server.
3. Navigate between the five pages.
4. Test all interactive features.
